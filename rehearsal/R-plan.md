# Dress rehearsal plan (decided 22 Nov 2026, before the rehearsal)

The rehearsal follows `protocol/run_sheet.md` with these three differences, set by the lab's principal before it starts. No forecast existed when they were made.

| # | Difference from the run sheet | Why |
|---|---|---|
| 1 | Deliberate runs twice, not three times: the scored run (starting claim) and the twin run. The repeat test is deferred. | Plan usage. The rehearsal's first job is to measure what a checkpoint costs. |
| 2 | The runner pauses at four points and asks the principal to read the plan's usage figures: before the first model call, after the ten Fable calls, after the scored Deliberate run, after the twin run. The readings go into the rehearsal record. | The plan's limits are not published as numbers, so cost can only be measured. The runner cannot see the usage figures itself. |
| 3 | The runner session uses a lighter model than Fable. The model arms are unchanged: the ten baseline calls use Fable at high effort and Deliberate uses its default models. | The runner conducts and records but forecasts nothing, so its model does not touch the comparison. |

A cut order for scored checkpoints (what is dropped first if plan usage is short) is fixed after these measurements and before the freeze.
